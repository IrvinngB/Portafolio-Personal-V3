# Irvin Benitez - Portfolio

Portafolio profesional desarrollado con Vue 3, TypeScript y Tailwind CSS.

## Tecnologías

- **Vue 3** - Framework con Composition API
- **TypeScript** - Tipado estático
- **Tailwind CSS** - Estilos utilitarios
- **Vite** - Build tool
- **GSAP** - Animaciones
- **Lucide Icons** - Iconografía

## Características

- Diseño responsive (mobile-first)
- Modo oscuro/claro con persistencia
- Internacionalización (ES/EN)
- Animaciones suaves con GSAP
- Lazy loading de componentes
- Formulario de contacto funcional
- Accesibilidad (WCAG AA)
- SEO optimizado

## Instalación

```bash
# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build producción
npm run build

# Preview
npm run preview
```

## Configuración del Formulario de Contacto

El formulario usa [Web3Forms](https://web3forms.com/). Para activarlo:

1. Crea una cuenta gratuita en Web3Forms
2. Obtén tu Access Key
3. Reemplaza `YOUR_WEB3FORMS_ACCESS_KEY` en `ContactSection.vue`

## Estructura del Proyecto

```
src/
├── components/     # Componentes Vue
├── composables/    # Lógica reutilizable
├── data/           # Datos del CV (ES/EN)
├── types/          # Tipos TypeScript
└── assets/         # Recursos estáticos
```
